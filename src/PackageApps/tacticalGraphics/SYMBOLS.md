# Task symbols — what is implemented, and in what state

Generated by `node tools/control-measures/symbols-doc.mjs` from the built
package and `reference/control-measures/INDEX.json`. Re-run it after adding
symbols; do not hand-edit, because a hand-maintained list of this length
disagrees with the catalog within a week and does it quietly.

The `/symbols` page of the harness app renders every one of these live —
this document is the inventory, that page is the picture.

## How to read it

| Column | Meaning |
|---|---|
| **Symbol** | The catalog name, and what `paramsFor`/`getParts` take. |
| **Reference** | The row(s) in the APP-6D extract this was authored from. Blank means it came from `TACTIC_TASK_CATALOG` or is a plain shape the publication assumes rather than tabulates. |
| **Anchor** | `unitAnchor`, and the handle it resolves to. This is where a unit sits once an order is assigned, and an ordinary drag handle until then — `start` on the cone markers is their tip, `start` on an axis is the arrow's tail. `_(derived)_` means it resolves to a position with no handle behind it: the midpoint of an obstacle row, say, which is the right place for the symbol and not something a unit can be glued to. |
| **Handles** | How many drag handles the symbol exposes at its defaults. |
| **Label** | The text it draws by default. _caller's_ means the slot exists and starts empty because the only text the symbol carries is a designation, an altitude or a date-time group. `—` means it draws no text at all. |
| **Task** | The `TACTIC_TASK_CATALOG` id this graphic satisfies, where it has one. |

Every symbol listed is in the catalog and drawing: `catalogSanity.test.ts`
asserts that each one produces finite geometry inside the parameter box with
handles that land where they are dragged, and it enumerates the catalog, so
nothing here is untested. Whether a graphic matches its doctrine is a
separate question, and each symbol's own file records the evidence it was
authored from — the abbreviations in particular, several of which were read
out of the publication's own templates with `tools/control-measures/text.mjs`.
